地球在线（Earth Online）是一款全本地运行的个人成长与记账工具。
你的每一次习惯打卡、每一条待办、每一笔账单，都会被量化为角色的经验值与金币——
在一张从「出生」开始生长的人生地图上，看着自己一步步升级。

无账号、无广告、无内购，所有数据只存于你的设备。

## 游戏化的人生属性面板

### 🎛️ 人生面板

生命时钟、年龄电量、薪水轮盘、碳基生命、宇宙旅程……
把抽象的"人生进度"做成一眼可读的属性卡片，打开 App 就看见自己当前的状态。

![人生面板/界面预览](assets/1.jpg)

### 🌿 生命藤蔓

从唯一根节点「出生」生长的人生时间地图：高考、大学、第一份工作、马拉松……
目标像 Git 分支一样分叉延伸，每个节点下挂载每日习惯与待办——
让你知道今天的每一次打卡，究竟通向哪里。

### 💰 财富账本

多币种账户、资产台账与租赁记录，高精度定点数计算杜绝浮点误差，
每日同步欧洲央行（ECB）公开汇率，海外资产一本算清。

### 🏆 成就系统

现实中的坚持会实时结算为 EXP 与金币，达成里程碑解锁成就，
把"变好"这件事，变成看得见的正反馈。

## 为什么是地球在线

- 🔒 **数据只在本机** —— 无账号、无注册，个人数据不上传任何服务器
- 🚫 **零打扰** —— 无广告、无内购、无推送
- 💾 **数据自主** —— 一键生成本地备份，文件由你自己保管
- 📴 **离线可用** —— 核心功能完全离线运行，仅汇率同步时联网
