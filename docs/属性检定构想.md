# 属性检定（人类能力测试平台）构想

> 2026-09-27 由用户构想整理，作为「属性检定」板块的产品愿景文档。实施范围与架构约束见 `docs/架构决策.md` #16。

## 起点观察

人与人之间存在稳定的个体差异，这些差异可以通过一组标准化任务进行测量。本板块的目标不是娱乐式「你是什么天才」测试，而是建立**可重复、可量化、能逐渐积累数据**的实验型测试集。

## 核心设计原则

- 结果拆解为 **原始数据 → 能力指标 → 综合画像**，而不是「做完题 → AI 告诉你是什么人」。
- 不把所有东西都叫「天赋」：反应时间 220ms 是可直接测量的行为指标；「你意志力很强」则涉及测量模型、题目设计、情境依赖，需谨慎。
- 结果必须带**常模百分位**（如：视觉反应时间 241ms → 第 73 百分位），比「优秀 ⭐⭐⭐」有意义得多。本站为纯静态零隐私架构，百分位来自**内嵌的文献/公开常模**（标注来源与局限），自建人群数据库留待未来有后端时实现。

## 长期愿景

- **能力画像**：个人 → 感知 / 认知 / 学习 / 行为倾向 / 人格 五域，攒够 5 项以上出雷达图（能力指纹）。
- **纵向追踪**：本机 localStorage 保存历史，多次测试看百分位变化（P62 → P68 → P74），未来可关联睡眠、年龄、训练等因素。跨设备同步依赖后端，与零隐私人设冲突，暂不做。
- **与 AI 连接**：测试产生客观行为数据，AI 负责解释、制定训练方案、长期追踪。

## V1 范围（本批实现）

1. **视觉简单反应**：5 轮取中位数，参考分布见组件内标注；
2. **选择反应**：4 选 1，正确轮中位数 + 正确率；
3. **数字广度**：正向广度递进（2 轮通过进位），粗略分档百分位。

## 明确不做（现阶段）

- 自建人群数据库 / 服务器端数据收集（零隐私人设）；
- 跨设备同步；
- 临床或诊断用途的任何声明——所有结果是**行为指标参考，非医学/心理诊断**；
- 结果页社交分享比拼（避免把测量变成绩效焦虑）。
