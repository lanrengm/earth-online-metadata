# 升级计划：Vue SPA → Astro + React（知识博客 + 工具融合站）

> 状态：进行中 · 分支：dev · **改版验收前不执行 `tools\dev release`**

## 一、背景与目标

- 网站从「App 宣传单页 + 工具占位」升级为**知识博客 + 工具站融合**形态。
- 博客由 AI 辅助产出多媒体形态内容（图表、数据、交互组件），每次更新相当于一次网站 release。
- 界面风格：fnos 风格（现有 M3 设计令牌 tokens.css 为根基，原样保留）。
- 开发模式：AI-first（React 生态训练数据占优、JSX 单语言生成更稳）。

## 二、技术栈（版本以 package.json 实装为准，同步记录到 AGENTS.md）

| 类别 | 选型 | 协议 |
|---|---|---|
| 站点框架 | Astro 5 | MIT |
| 交互组件 | React 19 + @astrojs/react | MIT |
| 文章格式 | MDX（@astrojs/mdx），图表/组件直接内嵌 | MIT |
| 样式 | tokens.css 设计令牌 + 原生 CSS（不引入 Tailwind） | — |
| 托管 | GitHub Pages（gh-pages workflow 不变） | — |

卸载：vue / vue-router / @vitejs/plugin-vue / vite（Astro 自带 Vite）。

## 三、路由规划

| 路由 | 内容 | 说明 |
|---|---|---|
| `/` | **默认进工具页**（redirect → `/tools/`） | 主页定位为工具站入口 |
| `/tools/` | 工具合集页 | React 岛屿挂载点，沿用「集中注册工具表」模式 |
| `/articles/` | 文章列表 | 博客首页 |
| `/articles/<slug>/` | 文章详情 | MDX 渲染，多媒体组件内嵌 |
| `/privacy/`、`/terms/` | 隐私政策、用户协议 | 由 Vue 版直接移植 |

- 旧 hash 路由（`/#/tools` 等）流量小，不做重定向。
- Astro `redirects` 配置生成静态跳转，gh-pages 可用。

## 四、验收标准

### 工具页（对标 it-tools.tech）

- [ ] 首屏即工具：搜索框 + 分类/网格工具卡片，无多余营销内容
- [ ] 工具卡片：图标 + 名称 + 一句话描述，hover 反馈，点击直达工具
- [ ] 新增工具 = 注册表加一条 + 一个 React 组件，零页面改动
- [ ] 纯本地计算、无登录、无后端（与现站原则一致）
- [ ] 工具内布局延续 fnos/M3 风格（卡片、圆角、令牌变量）

### 博客页（对标 distill.pub）

- [ ] 文章页阅读体验：宽排版、标题层级清晰、目录/元信息（日期、标签）齐备
- [ ] 支持内嵌交互/图表组件（MDX + React），先留占位组件跑通管线，图表库待需求落地再选
- [ ] 列表页按时间倒序，卡片含标题/日期/摘要
- [ ] 文章 = `src/content/articles/` 下一个 `.mdx` 文件，frontmatter 定义元信息
- [ ] 暗色模式下图表/代码块可读

## 五、实施步骤

1. **写本计划文档**（本文件）
2. **依赖切换**：卸 Vue 系，装 Astro + React + MDX；删除 index.html / vite.config.js / 旧 Vue 源码
3. **基建**：astro.config.mjs（site/base/redirects）+ global.css（tokens.css 原样保留）+ Base.astro 外壳 + 主题防闪内联脚本 + AppNav/Footer 移植
4. **页面移植**：`/` redirect、`/tools/`（React 岛屿 + 空注册表）、`/privacy/`、`/terms/`
5. **博客管线**：articles content collection + 列表页 + 详情页 + 示例 MDX 文章（含占位图表组件）
6. **验证**：`npm run build` + `preview` 全页面走查（不发 release）
7. **AGENTS.md**：写入技术栈版本、新目录结构、发文章/加工具的操作指引
