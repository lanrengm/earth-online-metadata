## 为什么改版

这个站点最初只是 Earth Online（人生面板）的宣传页。随着在线工具和知识内容的需求增长，单页 SPA 的形态撑不住了。这次改版把站点重构成**博客 + 工具融合站**：

- **工具页**对标 [it-tools.tech](https://it-tools.tech)：首屏即搜索框与工具网格，新增工具零页面改动；
- **博客页**对标 [distill.pub](https://distill.pub)：沉浸式阅读排版，图表与交互组件直接内嵌在文章里。

## 技术栈决策

| 决策项 | 选择 | 理由 |
|---|---|---|
| 站点框架 | Astro | 内容站原生支持，默认零 JS，博客页快 |
| 交互组件 | React | AI 训练数据占优，JSX 单语言生成更稳 |
| 文章格式 | MDX | Markdown 里直接内嵌 React 组件与图表 |
| 样式 | M3 设计令牌 + 原生 CSS | fnos 风格延续，不引入额外抽象 |

## 工作方式的变化

对读者来说，变化是：以后这里会持续产出两类内容——**带数据图表的知识文章**和**即开即用的本地小工具**。对开发者（AI）来说，发一篇博客 = 在 `src/content/articles/` 放一个 `.mdx` 文件；上一个工具 = 注册表加一条记录。每次更新等同于一次网站 release。

## 下一步

工具区目前还是空的，第一批工具会围绕人生面板的核心能力展开（人生统计、记账演算类）；文章方面会先从「人生量化」的数据方法论写起。图表库的选型等第一篇重图表的文章立项时再定。
